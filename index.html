Statistik pengunjung

Data disimpan di database gratis milikmu sendiri, tanpa batas 6 jam.

Pasang dalam 5 menit (gratis, tanpa kartu kredit)

  1. Buka console.firebase.google.com, buat proyek baru (matikan Google Analytics, tidak perlu).
  2. Menu Build → Realtime Database → Create Database. Pilih lokasi Singapore, mulai dengan locked mode.
  3. Buka tab Rules, ganti isinya dengan ini lalu Publish: 
    {
  "rules": {
    "visits": {
      ".read": true,
      "$id": {
        ".write": "!data.exists()",
        ".validate": "newData.hasChildren(['t','s','p','v'])"
      }
    }
  }
}
  4. Salin alamat database (bentuknya https://nama-proyek-default-rtdb.asia-southeast1.firebasedatabase.app) dan tempel di bawah.

Kode pelacak

Tempel kode ini sebelum </body> di setiap game atau halaman yang mau dihitung pengunjungnya. Satu kode bisa dipakai di semua situsmu; dashboard memisahkan per alamat situs.
